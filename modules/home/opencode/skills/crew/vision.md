# vision

Image analysis subagent: it reads image files and returns descriptions or answers.

## Use it for

Screenshots, photos, diagrams, and UI captures when you cannot view images yourself, or when you need a second, detailed look.

## Brief

- The absolute path of each image; it only reads files, so save browser screenshots to a file first.
- The specific questions: what to find, read, compare, or extract (text, layout, error messages, values).
- The answer format, for example a list of findings or the exact text on screen.
